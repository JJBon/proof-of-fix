# calibration c59: transpose() doesn't swap anything

`transpose([[1, 2], [3, 4]])` returns `[[[1, 2]], [[3, 4]]]`; expected `[[1, 3], [2, 4]]`.

`transpose(rows)` in `calibration/c59.py` should give: rows and columns swapped (the rows are of equal length).

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c59.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C59`) runs.
