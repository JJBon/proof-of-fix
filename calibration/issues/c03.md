# calibration c03: last_word() returns '' when the text ends with spaces

`last_word("hello world  ")` returns `''`; expected `"world"`.

`last_word(text)` in `calibration/c03.py` should give: The last whitespace-separated word of text, or '' for blank text.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c03.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C03`) runs.
