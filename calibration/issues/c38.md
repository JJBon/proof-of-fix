# calibration c38: snake_case() starts PascalCase names with an underscore

`snake_case("PascalCase")` returns `'_pascal_case'`; expected `"pascal_case"`.

`snake_case(name)` in `calibration/c38.py` should give: A camelCase or PascalCase name in snake_case.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c38.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C38`) runs.
