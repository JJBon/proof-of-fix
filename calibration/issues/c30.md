# calibration c30: range_sum() leaves out its upper bound

`range_sum(1, 4)` returns `6`; expected `10`.

`range_sum(a, b)` in `calibration/c30.py` should give: The sum of the integers from a to b inclusive; 0 when a > b.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c30.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C30`) runs.
