# calibration c44: remove_none() drops zeros too

`remove_none({"a": 0, "b": None})` returns `{}`; expected `{"a": 0}`.

`remove_none(d)` in `calibration/c44.py` should give: A new dict: d without the keys whose value is None.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c44.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C44`) runs.
