# calibration c60: expand_tabs() ignores tab stops

`expand_tabs("a\tb", 4)` returns `'a    b'`; expected `"a   b"`.

`expand_tabs(s, width)` in `calibration/c60.py` should give: s (one line) with each tab replaced by spaces up to the next multiple of width.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c60.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C60`) runs.
