# calibration c36: truncate() returns more than n characters

`truncate("abcdefgh", 6)` returns `'abcdef...'`; expected `"abc..."`.

`truncate(s, n)` in `calibration/c36.py` should give: s cut to at most n characters (n >= 3), ending with '...' when cut; the '...' counts toward n.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c36.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C36`) runs.
