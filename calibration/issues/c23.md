# calibration c23: gcd() always returns 0

`gcd(12, 18)` returns `0`; expected `6`.

`gcd(a, b)` in `calibration/c23.py` should give: The greatest common divisor of two non-negative integers.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c23.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C23`) runs.
