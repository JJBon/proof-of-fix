# calibration c34: hamming() accepts strings of different lengths

`hamming("abc", "ab")` returns `0`; expected a ValueError.

`hamming(a, b)` in `calibration/c34.py` should give: How many positions differ between two strings of equal length; ValueError if their lengths differ.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c34.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C34`) runs.
