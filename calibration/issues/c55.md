# calibration c55: rgb_to_hex() drops leading zeros

`rgb_to_hex(255, 0, 128)` returns `'#ff080'`; expected `"#ff0080"`.

`rgb_to_hex(r, g, b)` in `calibration/c55.py` should give: The colour as '#rrggbb', in lower case.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c55.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C55`) runs.
