# calibration c40: split_csv_line() splits inside quoted fields

`split_csv_line('a,"b,c",d')` returns `['a', '"b', 'c"', 'd']`; expected `["a", "b,c", "d"]`.

`split_csv_line(line)` in `calibration/c40.py` should give: The fields of one CSV line: commas separate fields; double quotes enclose a field that may hold commas.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c40.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C40`) runs.
