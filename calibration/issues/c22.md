# calibration c22: strip_prefix() strips characters, not the prefix

`strip_prefix("aab", "a")` returns `'b'`; expected `"ab"`.

`strip_prefix(s, prefix)` in `calibration/c22.py` should give: s without prefix when s starts with it, else s unchanged.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c22.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C22`) runs.
