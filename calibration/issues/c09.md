# calibration c09: safe_div() ignores its default

`safe_div(1, 0, -1)` returns `0`; expected `-1`.

`safe_div(a, b, default)` in `calibration/c09.py` should give: a / b, or default when b is 0.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c09.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C09`) runs.
