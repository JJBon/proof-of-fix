# calibration c42: grade() gives a B for 90

`grade(90)` returns `'B'`; expected `"A"`.

`grade(score)` in `calibration/c42.py` should give: The letter grade: A from 90, B from 80, C from 70, D from 60, else F.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c42.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C42`) runs.
