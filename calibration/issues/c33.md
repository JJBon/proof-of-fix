# calibration c33: is_sorted() refuses equal neighbours

`is_sorted([1, 2, 2, 3])` returns `False`; expected `True`.

`is_sorted(xs)` in `calibration/c33.py` should give: Whether xs is in non-decreasing order.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c33.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C33`) runs.
