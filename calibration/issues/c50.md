# calibration c50: is_anagram() is case-sensitive

`is_anagram("Listen", "Silent")` returns `False`; expected `True`.

`is_anagram(a, b)` in `calibration/c50.py` should give: Whether a and b use the same letters, ignoring case and spaces.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c50.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C50`) runs.
