# calibration c02: mean() divides by one too many

`mean([1, 2, 3])` returns `1.5`; expected `2.0`.

`mean(xs)` in `calibration/c02.py` should give: The arithmetic mean of xs; 0.0 for an empty list.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c02.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C02`) runs.
