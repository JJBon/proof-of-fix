# calibration c49: compound() computes simple interest

`compound(100, 0.1, 2)` returns `120.0`; expected `121.0`.

`compound(principal, rate, years)` in `calibration/c49.py` should give: principal grown by rate (0.05 for 5 %) compounded yearly, rounded to cents.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c49.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C49`) runs.
