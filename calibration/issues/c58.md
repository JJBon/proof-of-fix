# calibration c58: safe_int() refuses negative numbers

`safe_int("-5", 0)` returns `0`; expected `-5`.

`safe_int(s, default)` in `calibration/c58.py` should give: int(s), or default when s isn't an integer.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c58.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C58`) runs.
