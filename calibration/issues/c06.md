# calibration c06: median() of an even-length list is wrong

`median([4, 1, 3, 2])` returns `3`; expected `2.5`.

`median(xs)` in `calibration/c06.py` should give: The median of a non-empty list.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c06.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C06`) runs.
