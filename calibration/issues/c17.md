# calibration c17: days_in_month() gives February 28 days in a leap year

`days_in_month(2, True)` returns `28`; expected `29`.

`days_in_month(month, leap)` in `calibration/c17.py` should give: The number of days in month (1-12); leap says whether the year is a leap year.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c17.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C17`) runs.
