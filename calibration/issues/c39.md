# calibration c39: dot() adds instead of multiplying

`dot([1, 2, 3], [4, 5, 6])` returns `21`; expected `32`.

`dot(u, v)` in `calibration/c39.py` should give: The dot product of two vectors of equal length.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c39.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C39`) runs.
