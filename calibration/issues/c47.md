# calibration c47: kebab_to_camel() capitalizes the first word

`kebab_to_camel("foo-bar")` returns `'FooBar'`; expected `"fooBar"`.

`kebab_to_camel(s)` in `calibration/c47.py` should give: A kebab-case name in camelCase: 'foo-bar-baz' -> 'fooBarBaz'.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c47.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C47`) runs.
