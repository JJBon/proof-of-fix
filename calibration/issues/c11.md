# calibration c11: word_count() counts empty words between spaces

`word_count("a  b")` returns `3`; expected `2`.

`word_count(text)` in `calibration/c11.py` should give: How many words text has, separated by any whitespace.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c11.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C11`) runs.
