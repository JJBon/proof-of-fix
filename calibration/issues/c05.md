# calibration c05: is_leap() says 1900 was a leap year

`is_leap(1900)` returns `True`; expected `False`.

`is_leap(year)` in `calibration/c05.py` should give: Whether year is a leap year in the Gregorian calendar.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c05.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C05`) runs.
