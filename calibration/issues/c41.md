# calibration c41: interleave() drops the longer list's rest

`interleave([1, 2, 3], ["a"])` returns `[1, 'a']`; expected `[1, "a", 2, 3]`.

`interleave(a, b)` in `calibration/c41.py` should give: a's and b's items alternated, the longer list's rest at the end.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c41.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C41`) runs.
