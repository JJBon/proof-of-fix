# calibration c15: flatten() keeps only each list's first item

`flatten([[1, 2], [3]])` returns `[1, 3]`; expected `[1, 2, 3]`.

`flatten(xss)` in `calibration/c15.py` should give: A list of lists flattened by one level.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c15.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C15`) runs.
