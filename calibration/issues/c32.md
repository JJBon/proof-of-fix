# calibration c32: rot13() mangles upper-case letters

`rot13("Hello")` returns `'oryyb'`; expected `"Uryyb"`.

`rot13(s)` in `calibration/c32.py` should give: s with each ASCII letter rotated by 13 places; anything else unchanged.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c32.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C32`) runs.
