# calibration c04: count_vowels() misses upper-case vowels

`count_vowels("Apple")` returns `1`; expected `2`.

`count_vowels(s)` in `calibration/c04.py` should give: How many vowels (a, e, i, o, u, in either case) s has.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c04.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C04`) runs.
