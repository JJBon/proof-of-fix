# calibration c07: chunk() drops the last, shorter chunk

`chunk([1, 2, 3, 4, 5], 2)` returns `[[1, 2], [3, 4]]`; expected `[[1, 2], [3, 4], [5]]`.

`chunk(xs, n)` in `calibration/c07.py` should give: xs split into lists of n items; the last one may be shorter.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c07.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C07`) runs.
