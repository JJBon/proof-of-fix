# calibration c35: seconds_to_hms() counts the hours' minutes too

`seconds_to_hms(3725)` returns `'1:62:05'`; expected `"1:02:05"`.

`seconds_to_hms(s)` in `calibration/c35.py` should give: 'H:MM:SS' for a number of seconds.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c35.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C35`) runs.
