# calibration c52: moving_average() leaves out the last window

`moving_average([1, 2, 3, 4], 2)` returns `[1.5, 2.5]`; expected `[1.5, 2.5, 3.5]`.

`moving_average(xs, k)` in `calibration/c52.py` should give: The average of each window of k consecutive items of xs.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c52.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C52`) runs.
