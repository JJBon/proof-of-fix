# calibration c12: fizzbuzz() never says FizzBuzz

`fizzbuzz(15)` returns `'Fizz'`; expected `"FizzBuzz"`.

`fizzbuzz(n)` in `calibration/c12.py` should give: 'Fizz' for a multiple of 3, 'Buzz' of 5, 'FizzBuzz' of both, else n as text.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c12.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C12`) runs.
