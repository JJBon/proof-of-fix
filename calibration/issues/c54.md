# calibration c54: count_lines() counts a line after the final newline

`count_lines("a\nb\n")` returns `3`; expected `2`.

`count_lines(text)` in `calibration/c54.py` should give: How many lines text has: a final newline doesn't start another, and '' has none.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c54.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C54`) runs.
