# calibration c21: max_index() of an empty list is 0

`max_index([])` returns `0`; expected `-1`.

`max_index(xs)` in `calibration/c21.py` should give: The index of the largest item (the first one if tied); -1 for an empty list.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c21.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C21`) runs.
