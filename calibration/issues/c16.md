# calibration c16: is_palindrome() is case-sensitive

`is_palindrome("Racecar")` returns `False`; expected `True`.

`is_palindrome(s)` in `calibration/c16.py` should give: Whether s reads the same backwards, ignoring case and anything not a letter or digit.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c16.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C16`) runs.
