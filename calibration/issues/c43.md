# calibration c43: count_char() is case-sensitive

`count_char("Banana", "b")` returns `0`; expected `1`.

`count_char(s, ch)` in `calibration/c43.py` should give: How many times the letter ch occurs in s, ignoring case.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c43.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C43`) runs.
