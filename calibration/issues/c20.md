# calibration c20: to_celsius() gets the order of operations wrong

`to_celsius(212)` returns `194.22`; expected `100.0`.

`to_celsius(f)` in `calibration/c20.py` should give: Fahrenheit to Celsius, rounded to 2 decimals.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c20.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C20`) runs.
