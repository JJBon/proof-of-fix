# calibration c01: clamp() doesn't limit a value to its range

`clamp(5, 0, 3)` returns `0`; expected `3`.

`clamp(x, lo, hi)` in `calibration/c01.py` should give: x limited to the range [lo, hi].

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c01.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C01`) runs.
