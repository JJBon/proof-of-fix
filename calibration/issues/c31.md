# calibration c31: merge_dicts() changes its first argument

`(lambda a: (merge_dicts(a, {"y": 2}), a))({"x": 1})` returns `({'x': 1, 'y': 2}, {'x': 1, 'y': 2})`; expected `({"x": 1, "y": 2}, {"x": 1})`.

`merge_dicts(a, b)` in `calibration/c31.py` should give: A new dict: a's items updated by b's. Neither input is changed.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c31.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C31`) runs.
