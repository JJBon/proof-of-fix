# calibration c27: sum_digits() fails on a negative number

`sum_digits(-123)` raises ValueError; expected `6`.

`sum_digits(n)` in `calibration/c27.py` should give: The sum of the decimal digits of an integer, its sign ignored.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c27.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C27`) runs.
