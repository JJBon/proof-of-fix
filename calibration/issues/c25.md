# calibration c25: nth_fib() is off by one

`nth_fib(10)` returns `89`; expected `55`.

`nth_fib(n)` in `calibration/c25.py` should give: The n-th Fibonacci number: nth_fib(0) = 0, nth_fib(1) = 1.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c25.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C25`) runs.
