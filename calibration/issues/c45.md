# calibration c45: bin_search() misses the last item

`bin_search([1, 3, 5], 5)` returns `-1`; expected `2`.

`bin_search(xs, x)` in `calibration/c45.py` should give: The index of x in the sorted list xs, or -1.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c45.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C45`) runs.
