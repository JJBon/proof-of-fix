# calibration c13: reverse_words() reverses the letters, not the words

`reverse_words("one two three")` returns `'eerht owt eno'`; expected `"three two one"`.

`reverse_words(s)` in `calibration/c13.py` should give: The words of s in reverse order, joined by single spaces.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c13.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C13`) runs.
