# calibration c08: title_case() keeps upper-case letters after the first

`title_case("hello WORLD")` returns `'Hello WORLD'`; expected `"Hello World"`.

`title_case(s)` in `calibration/c08.py` should give: Each space-separated word's first letter in upper case and the rest in lower case.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c08.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C08`) runs.
