# calibration c57: sort_by_length() sorts longest first

`sort_by_length(["ccc", "a", "bb"])` returns `['ccc', 'bb', 'a']`; expected `["a", "bb", "ccc"]`.

`sort_by_length(words)` in `calibration/c57.py` should give: words sorted from shortest to longest, ties kept in their order.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c57.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C57`) runs.
