# calibration c14: percent() returns a fraction, not a percentage

`percent(1, 4)` returns `0.2`; expected `25.0`.

`percent(part, whole)` in `calibration/c14.py` should give: part as a percentage of whole, rounded to 1 decimal; 0.0 when whole is 0.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c14.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C14`) runs.
