# calibration c46: escape_html() escapes its own entities again

`escape_html("<b>")` returns `'&amp;lt;b&amp;gt;'`; expected `"&lt;b&gt;"`.

`escape_html(s)` in `calibration/c46.py` should give: s with &, <, > and " replaced by their HTML entities.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c46.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C46`) runs.
