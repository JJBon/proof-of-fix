# calibration c18: initials() keeps lower-case letters

`initials("ada lovelace")` returns `'al'`; expected `"AL"`.

`initials(name)` in `calibration/c18.py` should give: The upper-case initials of each word of name.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c18.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C18`) runs.
