# calibration c26: pad_left() cuts text longer than the width

`pad_left("12345", 3, "0")` returns `'123'`; expected `"12345"`.

`pad_left(s, width, fill)` in `calibration/c26.py` should give: s right-aligned in width characters, padded on the left with fill; a longer s unchanged.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c26.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C26`) runs.
