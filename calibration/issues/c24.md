# calibration c24: parse_bool() is case-sensitive

`parse_bool("Yes")` returns `False`; expected `True`.

`parse_bool(s)` in `calibration/c24.py` should give: True for 'true', 'yes', '1' or 'on' in any case with surrounding spaces ignored, else False.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c24.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C24`) runs.
