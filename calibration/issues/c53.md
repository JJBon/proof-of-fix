# calibration c53: json_path() raises KeyError for a missing path

`json_path({"a": {"b": 1}}, "a.c")` raises KeyError; expected `None`.

`json_path(d, path)` in `calibration/c53.py` should give: The value at a dotted path such as 'a.b.c' in nested dicts, or None when it is missing.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c53.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C53`) runs.
