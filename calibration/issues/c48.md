# calibration c48: weekday_name() raises IndexError, not ValueError

`weekday_name(7)` raises IndexError; expected a ValueError.

`weekday_name(i)` in `calibration/c48.py` should give: The weekday's name, 0 for Monday to 6 for Sunday; ValueError outside 0-6.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c48.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C48`) runs.
