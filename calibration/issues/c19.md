# calibration c19: running_total() is one item behind

`running_total([1, 2, 3])` returns `[0, 1, 3]`; expected `[1, 3, 6]`.

`running_total(xs)` in `calibration/c19.py` should give: The running sums of xs.

This is a calibration issue (calibration/README.md): a deliberate, small bug kept in this repository to qualify validators. A fix changes `calibration/c19.py` and sets its `FIXED` to `True`, so that the item's protected test (`tests/test_calibration.py`, class `C19`) runs.
